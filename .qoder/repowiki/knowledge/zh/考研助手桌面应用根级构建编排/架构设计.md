根目录作为 Electron 三进程项目的构建编排层：`package.json` 通过 `main: dist/main/main.js` 指定主进程入口，并在 `build` 字段内按 win/mac/linux 分别声明 NSIS/Dmg/AppImage 目标、图标与 nsis 选项，同时通过 `publish.provider=github` 启用 GitHub Releases 自动发布；`vite.config.ts` 将 `src/renderer` 设为 root，输出至 `dist/renderer`，并通过 `manualChunks` 将 vue/vue-router/pinia、element-plus、echarts 拆分为独立 vendor chunk 以优化缓存；`tsconfig.json` 启用 strict 模式并配置 `@/*` 路径别名指向渲染端源码，通过 project references 引用 `tsconfig.node.json` 单独编译主进程 TypeScript；开发流程由 `concurrently` 并行启动 Vite（5173 端口）与 Electron，并使用 `wait-on` 等待端口就绪后加载；构建前后通过 `predev`/`prebuild` 钩子执行 `scripts/copy-pdfjs-assets.mjs` 复制 pdfjs CMap/字体资源，确保离线 PDF 渲染可用。
