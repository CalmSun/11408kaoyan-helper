# 考研助手

一款专为考研人打造的桌面端备考助手应用，基于 Vue 3 + Electron + TypeScript 开发。

## ✨ 功能特性

### 📊 首页仪表盘
- 考研倒计时实时显示
- 今日学习数据概览
- 各科目学习时长分布统计
- 累计学习时长汇总
- 快捷功能入口

### ⏰ 考研倒计时
- 精确到秒的倒计时
- 环形进度条可视化
- 各科目复习建议（根据剩余天数智能推荐）
- 自定义考试日期和名称

### 🎯 真题成绩
- 录入历年（2009-2026）各科真题分数
- 408 专业课总分自动汇总
- 各科平均分、最高分、已练年份数统计
- 分数趋势折线图可视化
- 支持编辑、删除分数记录
- 按科目筛选记录

### 🍅 番茄钟
- 专注/短休息/长休息三种模式
- 自定义时长设置
- 学习科目记录
- 今日番茄统计
- 番茄历史记录

### ✅ 每日计划
- 添加每日学习任务
- 按科目分类标记
- 完成进度可视化
- 历史记录查看
- 一键全部完成/清除已完成
- 支持循环待办（每日自动重复）

### 🎴 背诵卡片
- 翻转卡片式记忆
- 自定义分类
- 背诵模式（记住了/没记住）
- 复习次数统计
- 随机打乱顺序

### 📈 数据统计
- 近7天学习时长趋势图
- 各科目学习占比饼图
- 每日番茄数柱状图
- 各科目学习时长柱状图
- GitHub 风格学习日历

### 📖 单词词典
- 考研高频/中频/低频词汇
- 单词搜索功能
- 音标、释义、例句
- 一键加入背诵卡片
- **本地词库未收录的单词自动在线查询**（音标 + 英文释义 + 中文释义）

### ⚙️ 设置
- 考试日期设置
- 番茄钟参数设置
- 数据导出/导入备份
- 数据清除功能

## 🛠️ 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **桌面端**: Electron
- **UI 组件**: Element Plus
- **状态管理**: Pinia
- **图表库**: ECharts
- **路由**: Vue Router
- **日期处理**: Day.js

## 📦 安装与运行

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run electron:dev
```

### 构建生产版本
```bash
# 构建当前平台
npm run electron:build

# 构建 Windows 版本
npm run electron:build:win

# 构建 macOS 版本
npm run electron:build:mac

# 构建 Linux 版本
npm run electron:build:linux
```

### 仅开发前端（浏览器模式）
```bash
npm run dev
```

## 💾 数据存储

所有数据都保存在本地浏览器的 LocalStorage 中，包括：
- 真题成绩数据
- 每日计划数据
- 背诵卡片数据
- 番茄钟记录
- 学习统计数据
- 设置项

**建议定期导出备份，防止数据丢失！**

## 🎯 使用说明

1. **首次使用**：先到设置页面设置你的考研日期
2. **每日打卡**：在每日计划中添加学习任务，完成后勾选
3. **专注学习**：使用番茄钟功能保持专注
4. **记录真题**：做历年真题后，在「真题成绩」页录入各科分数，追踪进步
5. **背诵单词**：利用背诵卡片和单词词典功能记忆单词（支持在线查询）
6. **查看统计**：定期查看学习数据，调整学习计划
