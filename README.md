## ✨ 项目亮点

1. **一站式考研全流程工具**：倒计时、番茄专注、每日计划、真题统计、背诵、词库、视频播放器、网易云听歌全部内置，无需多开软件
2. **液态玻璃拟态原生 UI**：全局磨砂玻璃卡片、双主题 + 护眼模式，低卡顿轻量化渲染
3. **完整离线可用**：所有学习数据本地双备份存储，不上传云端，隐私可控
4. **深度整合网易云音乐**：云盘、歌单、心动模式、评论、三种登录方式，全局顶栏悬浮播放器
5. **多格式内置播放器**：支持 MP4/MKV/AVI 等全主流视频，倍速、快捷键、音量增益、快进退
6. **可视化学习数据**：ECharts 图表展示 7 天时长、科目占比、真题分数趋势，一键导出 PDF 报告

## 📦 环境与运行部署

### 前置环境要求

- Node.js ≥ 18
- npm ≥ 9（推荐使用 npm 包管理器）

### 1. 安装全部依赖

```bash
npm install
```

### 2. Electron 桌面端开发模式（热更新）

```bash
npm run electron:dev
```

启动后 Vite 开发服务运行于 `http://localhost:5173`，主进程编译完成自动拉起桌面窗口。

### 3. 仅前端浏览器调试（无 Electron）

```bash
npm run dev
```

### 4. 打包生产安装包

```bash
# 打包当前操作系统对应安装包
npm run electron:build

# 仅构建 Windows 安装包
npm run electron:build:win

# 仅构建 macOS 安装包
npm run electron:build:mac

# 仅构建 Linux 安装包
npm run electron:build:linux
```

打包产物统一输出至项目 `release/` 文件夹。

## 🔌 已封装网易云 API 清单

所有网络请求均由 Electron 主进程代理转发，规避跨域 CORS、Referer、Cookie 限制；登录 Cookie 自动持久化并全局携带。

| 功能能力                   | 后端接口                                                            |
| -------------------------- | ------------------------------------------------------------------- |
| 歌曲关键词搜索             | `/cloudsearch/get/web`                                              |
| 歌曲播放地址               | `/song/url/v1` 无资源自动降级 `/song/enhance/player/url`            |
| 歌词解析                   | `/lyric`                                                            |
| 二维码登录生成 / 轮询校验  | `/login/qrcode/unikey` → `/login/qrcode/client/login`               |
| 二维码图片生成             | 本地构造 qrurl，调用 `api.qrserver.com` 渲染                        |
| 手机号密码 / Cookie 登录   | `/login/cellphone` + 登录态校验接口                                 |
| 账号信息、用户详情         | `/w/nuser/account/get`、`/v1/user/detail`                           |
| 我的歌单、歌单完整曲目     | `/user/playlist`、`/v6/playlist/detail`                             |
| 收藏喜欢歌曲列表           | `/song/like/get`（批量拉取本地缓存）                                |
| 单首歌曲收藏 / 取消收藏    | `/song/like`（附加 X-antiCheatToken 反作弊令牌）                    |
| 歌曲评论分页列表           | `/v1/resource/comments/R_SO_4_{id}`                                 |
| 评论点赞 / 取消点赞        | `/v1/comment/like`、`/v1/comment/unlike`（附加反作弊令牌）          |
| 实时热搜榜单               | `/search/hot` (type=1111)                                           |
| 官方音乐排行榜             | `/toplist/detail` + 曲目详情接口                                    |
| 心动模式智能推荐           | `/playmode/intelligence/list`                                       |
| 个人云盘歌曲分页加载       | `/v1/cloud/get`                                                     |
