# 考研助手

一款专为考研人打造的桌面端备考助手应用，基于 Vue 3 + Electron + TypeScript 开发。

## ✨ 功能特性

### 📊 首页仪表盘
- 考研倒计时实时显示
- 今日学习数据概览（小时计）
- 各科目学习时长分布统计
- 累计学习时长汇总
- 应用使用时长统计（小时计）
- 天气展示（卡片底部）
- 快捷功能入口

### ⏰ 考研倒计时
- 精确到秒的倒计时
- 环形进度条可视化
- 各科目复习建议（根据剩余天数智能推荐）
- 自定义考试日期和名称

### 🎯 真题成绩
- 录入历年（2009-2026）各科真题分数
- 各科平均分、最高分、已练年份数统计
- 分数趋势折线图可视化
- 支持编辑、删除分数记录
- 按科目筛选记录

### 🍅 番茄钟
- 专注/短休息/长休息三种模式
- 自定义时长设置
- 学习科目记录
- 番茄历史记录
- **强制全屏**：设置页全局开关，专注运行时隐藏系统任务栏减少干扰
- **增强提醒**：完成时全屏提醒弹窗 + 个性化文案
- **声音区分**：工作完成上升旋律，休息结束下降旋律
- **倒计时预警**：最后5秒提示音 + 视觉闪烁
- **振动反馈**：支持振动的设备触觉反馈

### ✅ 每日计划
- 添加每日学习任务
- 按科目分类标记
- 完成进度可视化
- 历史记录查看（每日快照，含循环与普通计划）
- 一键全部完成/清除已完成
- 支持循环待办（每日自动重复）

### 🎨 主题与外观
- 深色/浅色双主题，支持跟随系统自动切换
- 护眼模式（暖色滤光降低蓝光）
- 浅色主题使用自定义背景图片，搭配玻璃拟态卡片
- 顶栏一键切换深浅色与护眼模式，设置页可选浅色/深色/跟随系统

### 🌤️ 天气（国内数据源）
- 中国天气网国内数据源，主进程代理请求，稳定可靠
- 顶栏天气组件：点击查看详情（实时温度/天气/湿度/风速/今日最高最低气温/观测时间）
- 城市选择：17 个常用城市快捷选择、任意城市搜索（返回候选点选），选择自动持久化
- 首页仪表盘同步展示当前天气
- 30 分钟本地缓存，网络失败静默降级

### 🎵 全局本地音乐
- 顶栏音乐组件：选择本地音频文件 / 选择音乐文件夹（递归扫描目录内全部音频）
- 大文件夹优化：仅扫描文件名清单，播放走私有协议流式读取，不再把文件内容读入内存
- 播放/暂停/下一首/音量调节，任意页面可用
- 播放列表面板：点击切歌、上一首、移除曲目、清空列表
- 仅播放本地文件，不联网

### 🪟 液态玻璃（Liquid Glass 统一封装）
- 全局卡片统一为液态玻璃观感：折射渐变底 + 高饱和滤镜折射背景色彩
- 顶部内亮线 + 顶部渐变高光 + 左上镜面光斑（伪元素承载，零额外滤镜开销）
- hover 时高光增强、轻浮起；深浅主题观感统一
- 长列表与网格卡片采用无滤镜轻量玻璃面，滚动流畅不掉帧
- 深色模式叠加细噪点纹理；不支持滤镜的环境自动降级为不透明底色
- Element Plus 弹窗、消息框、下拉浮层统一玻璃化

### 🎴 背诵卡片
- 翻转卡片式记忆
- 自定义分类
- 背诵模式（记住了/没记住）
- 复习次数统计
- 随机打乱顺序

### 📈 数据统计
- 近7天学习时长趋势图
- 各科目学习占比饼图
- 每日番茄数柱状图
- 各科目学习时长柱状图
- GitHub 风格学习日历
- **导出 PDF 学习报告**（学习总览/各科进度/专注时长分布）

### 📖 单词词典
- 考研高频/中频/低频词汇
- 单词搜索功能
- 音标、释义、例句
- 一键加入背诵卡片
- **本地词库未收录的单词自动在线查询**（音标 + 英文释义 + 中文释义）

### ⚙️ 设置
- 考试日期设置
- 番茄钟参数设置（含强制全屏全局开关，开启即生效）
- 开机自启动开关
- 数据导出/导入备份
- **数据目录自定义**：数据默认存于「我的文档\11408kaoyan-helper」（不在 C 盘应用数据区），可更改目录、一键打开、自动备份开关与立即同步
- 数据清除功能
- 账号管理（查看/登出/删除账号）
- 项目地址与应用内更新（检测/下载/安装）

## 🛠️ 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **桌面端**: Electron
- **UI 组件**: Element Plus
- **状态管理**: Pinia
- **图表库**: ECharts（按需引入）
- **路由**: Vue Router
- **日期处理**: Day.js
- **玻璃拟态**: 纯 CSS 统一封装（backdrop-filter 变量化）
- **应用更新**: electron-updater

## 📦 安装与运行

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run electron:dev
```

### 构建生产版本
```bash
# 构建当前平台
npm run electron:build

# 构建 Windows 版本
npm run electron:build:win

# 构建 macOS 版本
npm run electron:build:mac

# 构建 Linux 版本
npm run electron:build:linux
```

### 仅开发前端（浏览器模式）
```bash
npm run dev
```

## 💾 数据存储

所有数据实时保存在渲染进程的 LocalStorage 中，并自动快照同步到数据目录（双重保存），包括：
- 真题成绩数据
- 每日计划数据（含每日快照历史）
- 背诵卡片数据
- 番茄钟记录
- 学习统计数据
- 设置项（主题/护眼/自定义背景/天气缓存）
- 应用使用时长

数据目录默认为 `文档\11408kaoyan-helper`（不在 C 盘应用数据区），可在设置页更改为任意可写目录。目录内存放：
- `auto-backup.json` — 数据快照自动备份（每 5 分钟同步一次）
- `custom-bg.jpg` — 自定义背景图

**建议开启自动备份并将数据目录设在 C 盘以外的磁盘，数据更安全！**

## 🎯 使用说明

1. **首次使用**：先到设置页面设置你的考研日期
2. **每日打卡**：在每日计划中添加学习任务，完成后勾选
3. **专注学习**：使用番茄钟功能保持专注，可在设置页开启强制全屏屏蔽干扰
4. **记录真题**：做历年真题后，在「真题成绩」页录入各科分数，追踪进步
5. **背诵单词**：利用背诵卡片和单词词典功能记忆单词（支持在线查询）
6. **查看统计**：定期查看学习数据，导出 PDF 学习报告
