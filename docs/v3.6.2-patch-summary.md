### **简化后的 startDash 流程**

```typescript
// ✅ 最终方案：sourceopen → play()
async function startDash(videoTracks, audioTracks, seekSecOverride = -1): Promise<void> {
  // 1. 预清理历史缓冲
  await preCleanBuffers(videoEl.value)
  
  // 2. 简单 Codec 过滤（仅 isTypeSupported）
  const supportedVideo = videoTracks.filter(t => t.baseUrl && MediaSource.isTypeSupported(mseMime(t)))
  const vTrack = pickDashTrack(supportedVideo.length ? supportedVideo : videoTracks, currentQn.value)
  if (!vTrack || !MediaSource.isTypeSupported(mseMime(vTrack))) {
    throw new Error('无可用视频轨道')
  }
  
  // 3. 创建 MediaSource + Video 绑定
  stopDash()
  dashCtrl = new AbortController()
  const ms = new MediaSource()
  mediaSource = ms
  mediaSourceUrl = URL.createObjectURL(ms)
  videoEl.value.src = mediaSourceUrl
  
  // 4. sourceopen 回调内启动拉流管道 + 直接播放
  ms.addEventListener('sourceopen', () => {
    try {
      // 添加 SourceBuffer
      const vSb = ms.addSourceBuffer(vMime)
      dashBuffers.push(vSb)
      
      // 启动 DASH 拉流管道（保留 Range 定位）
      pumpTrack(`${vTok.baseUrl}?token=${vTok.token}`, vSb, ctrl, currentQn.value, seekSec)
      
      // 音频通道（如有）
      if (audioUsable) {
        const aSb = ms.addSourceBuffer(aMime)
        dashBuffers.push(aSb)
        pumpTrack(`${aTok.baseUrl}?token=${aTok.token}`, aSb, ctrl, currentQn.value, seekSec)
      }
      
      // 拖动进度条场景下的自动 seek
      if (seekSec > 0) scheduleSeekAfterReady(seekSec, vSb, ms)
    } catch (err) {
      playerError.value = `播放初始化失败：${(err as Error).message}`
    }
  }, { once: true })
}
```

## 💡 设计原则总结

**"Less is More"** - MSE 播放器的最佳实践：

1. **信任浏览器原生能力**：不干预 playbackRate / currentTime / play()
2. **最小化事件监听**：只关注 sourceopen + error
3. **保持管道一致性**：pumpTrack 与 appendWithQuotaGuard 为核心
4. **容错优于优化**：静默降级 > 主动报错
5. **Range 定位是王道**：拖动进度条场景下最重要
