## v3.6.2 晚：修复流拉取 502 与播放自动停止（BiliBiliPanel.vue）

- **HTTP 502 根因**：`startDash` 只用 `baseUrl` 单地址拉流，B 站 `backupUrl` 备用 CDN 从未使用；主节点 502 时直接报"流拉取失败（HTTP 502）"。
- **修复**：候选地址 = `[baseUrl, ...backupUrl]` 全部签发代理 token；`pumpTrack(urls, ...)` 阶段一按地址轮换（非 2xx/网络异常 continue 切换）。
- **自动停止根因**：播放中 CDN 连接被掐断 → `reader.read()` 提前 `done` 或抛 TypeError → 旧逻辑 endOfStream/报错停住。
- **修复**：读取中断（`.catch`）或提前结束（对比 `durationSec` 未播到末尾）→ `recoverDashStream()` 从当前播放位置 Range 续播（复用 startDash seekSecOverride）；`dashRecoverySeq` 防并发 + 30 秒限 5 次防无限重启。
- 验证：vite build 临时目录 `✓ built`；vue-tsc 仅 2 个预存无关错误。
- 发布：commit 88a82b9，`git tag -f v3.6.2` + push main & tag（force）。

## v3.6.2 晚（三）：修复"视频无法正常播放"回归（commit 5dd6659）

- **回归根因**：上轮"提前断流自动恢复"用 `el.currentTime` 判断流是否读完——正常读完整个文件时 currentTime 可能还很小（刚起播/短文件快网络整文件迅速缓冲完），被误判为断流 → 无限重启恢复 → 30 秒 5 次上限后报"网络不稳定"，视频无法播放。
- **修复**：判据改为**本轨道 SourceBuffer 缓冲最远位置** `sbBufferedEnd(sb) < knownDur-2` 才算真断流；新增 `sbBufferedEnd`（不用 videoEl.buffered union，音频文件小常先读完会误判）。
- 经验：MSE/DASH 流"提前结束"判据必须看**本轨道缓冲最远位置**，不能用播放头 currentTime，也不能用音视频 union 缓冲。

## v3.6.2 晚（四）：播放器弹窗右移生效（commit f5b010b）

- 用户报：播放器弹窗没右移（截图显示弹窗左边缘紧贴左侧栏）。
- 根因：`.bili-player-dialog { margin-left: 160px }` 写在 `<style scoped>` 块中，而 el-dialog 设置了 `append-to-body` 渲染到 body 下，scoped CSS 的 `[data-v-xxx]` 属性选择器不会附加到 body 下的元素，**该选择器从 v3.6.2 起就匹配不上**，等同于未生效。
- 修复：把该样式从 `<style scoped>` 块移至文件末尾新增的**非 scoped `<style>` 块**，成为全局样式才能命中 body 下的 `.bili-player-dialog`。
- 经验：Vue3 + Element Plus 中 el-dialog `append-to-body=true` 时，自定义 class 的样式必须放在非 scoped 块（或用 `:global`/提升到 body），否则 scoped 的 `[data-v-xxx]` 永远匹配不到 body 下的元素。

## v3.6.2 晚（五）：播放自动停止（起播即暂停、无法继续）修复（commit c582cf8）

- 用户报：bili 视频"刚播放就暂停了，无法继续播放"。
- 根因：seek 续播/断流恢复走 `stopDash()`（撤销旧 blob URL → video 进入 paused）+ `startDash()`（仅改 src），但**没有任何地方调用 play()**。首次播放靠 `<video autoplay>`，而"仅改 src"的重新加载不会再次触发 autoplay → video 停在 paused，点播放也无缓冲数据推动 → 无法继续。
- 修复：`startDash` 的 sourceopen 里 `seekSec<=0` 时显式 `play()`；`scheduleSeekAfterReady` seek 定位后（含超时兜底分支）显式 `play()`。
- 经验：MSE 管道重启（撤销+重建 blob URL）后必须显式 `video.play()`，autoplay 属性对"仅改 src"的重新加载不生效。
