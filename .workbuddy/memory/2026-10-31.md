### liquid_glass_widgets 关键 API 规则（后续迁移必查）
- 入口：`await LiquidGlassWidgets.initialize()` + `LiquidGlassWidgets.wrap(brightnessResolver: Theme.maybeBrightnessOf, ...)`
- **质量分层**：`premium` 只给持久导航栏/英雄表面（GlassScaffold 自动提升 bar 到 premium）；
  **滚动内容卡片一律 `standard`**（premium 在 ListView 内渲染错乱）；`minimal` 无 shader 兜底。
- **禁止玻璃嵌套玻璃**：GlassButton/GlassIconButton/GlassChip 不放 GlassContainer.card 内；
  GlassSwitch/Slider/SegmentedControl 的玻璃是瞬态的，可放 solid 卡内。
- **回调命名陷阱**：GlassButton 用 `onTap`（默认构造 `icon` 必填、`label` 是无障碍语义不显示文字）；
  GlassIconButton 用 `onPressed`；GlassAppBar 用 `actions:[]` 不是 `trailing`；GlassChip.label 是 String。
- 带文字按钮用 `GlassButton.custom(child: ..., onTap: ...)`，或圆形图标按钮 `GlassButton(icon:..., onTap:...)` + 下方 Text。
- `GlassListTile` 有 `subtitle`（可选），`title` 必填。
- 主 barrel 导出：`package:liquid_glass_widgets/liquid_glass_widgets.dart`，禁止 import src/。

### 关键经验
- `flutter analyze` 是本地验证的核心：编译错误即时暴露，不用靠 CI 迭代。
- lint 陷阱：`sort_child_properties_last`（child 参数要放最后）、`prefer_const_constructors`、`unused_local_variable`。
- `GlassAppBar` 有 `leading` 参数（移动端汉堡按钮用）；`GlassButton` 默认构造 `icon` 必填、`label` 仅无障碍语义不显示文字。
- 番茄钟计时状态用全局单例 ChangeNotifier（对齐 Electron 的 pinia store 提升），切换页面不中断。
- 日期本地化：`toLocalDate`/`todayLocal` 用本地 YYYY-MM-DD 比较，避免 UTC 时区错位（东八区 0-8 点）。
